# MiniVerse — Guía para Copilot

Proyecto de minijuegos con Phaser 3, TypeScript y Vite. Primer juego: plataformas 2D pixel art retro original.

## Orden de trabajo
1. Leer `copilot-instructions.md`.
2. Revisar el código existente antes de modificarlo.
3. Ejecutar las tareas de `TASKS.md` por fases, verificando cada una.
4. Consultar `ART-DIRECTION.md` para cualquier recurso visual.
5. Consultar `GAME-DESIGN.md` para mecánicas y diseño de niveles.

No rehacer la estructura ya implementada sin una justificación técnica. No usar sprites, música, personajes ni niveles de Nintendo.
